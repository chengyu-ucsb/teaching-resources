# Teaching resources

Class activities and tools for communication courses at the University of Cincinnati, by Chengyu Fang.

**Home page: https://chengyu-ucsb.github.io/teaching-resources/**

| Tool | Link | Folder |
| --- | --- | --- |
| The Rate Race, an interactive simulation of classical management | https://chengyu-ucsb.github.io/teaching-resources/rate-race/ | `rate-race/` |
| Tallgrass crisis simulation, a classroom crisis communication case | https://chengyu-ucsb.github.io/teaching-resources/tallgrass/ | `tallgrass/` |
| Presentation scorecard, for audience scores and comments | https://chengyu-ucsb.github.io/teaching-resources/scorecard/ | `scorecard/` |

## Scorecard

The scorecard opens only with an access code. The page in this repository holds no class details. The class names, semester, criteria, and the names of teams or presenters come from a private Google Sheet after a valid code is entered, and scores are saved to that sheet. One code can open several classes; scorers then pick their class.

## Tallgrass

`tallgrass/` is a copy of the site in the `tallgrass-crisis-simulation` repository, taken on November 17, 2026. The narration and sound-effect build scripts stay in that repository.
