# Teaching resources

Class activities and tools for communication courses at the University of Cincinnati, by Chengyu Fang.

Site: https://chengyu-ucsb.github.io/teaching-resources/

| Folder | What it is |
| --- | --- |
| `rate-race/` | The Rate Race, an interactive simulation of classical management |
| `tallgrass/` | The Tallgrass crisis simulation, a classroom crisis communication case |
| `scorecard/` | Audience scorecard for class presentations |

## Scorecard

The scorecard opens only with an access code. The page in this repository holds no class details. The class name, semester, criteria, and the names of teams or presenters come from a private Google Sheet after a valid code is entered, and scores are saved to that sheet. The scorecard is not linked from the home page.

## Tallgrass

`tallgrass/` is a copy of the site in the `tallgrass-crisis-simulation` repository, taken on November 17, 2026. The narration and sound-effect build scripts stay in that repository.
